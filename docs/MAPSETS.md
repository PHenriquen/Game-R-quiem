# Echo Trial Mapsets

Echo Trials now separate **song-level metadata** from **difficulty-specific combat charts**.

The goal is simple: one piece of music can support several authored combat interpretations without duplicating audio, cover art or selection metadata.

## Why this exists

Rhythm games that survive on authored/community content generally treat a song as a container and its playable difficulties as separate charts. osu! groups beatmaps into beatmapsets while each `.osu` difficulty keeps its own gameplay data. Open-source projects such as Quaver likewise expose map/replay parsing and difficulty tooling as reusable content infrastructure, while Bemuse presents multiple difficulties per song.

Réquiem should borrow that **content architecture**, not their lane gameplay.

Transferable principles:

1. song identity is shared;
2. each difficulty remains an independently authored experience;
3. difficulty data should not be generated by merely deleting events from a harder chart;
4. validation must catch broken chart links before the game loads them;
5. selection UI should eventually read mapsets instead of scanning individual charts.

## Files

A mapset lives beside its charts:

```text
assets/beatmaps/
  vesper_first_echo.set.json
  first_echo_trial.json
```

Example:

```json
{
  "version": 1,
  "id": "vesper_first_echo",
  "title": "Primeiro Eco de Vesper",
  "artist": "prototype",
  "audio": "res://assets/audio/prototype/pulse_foundation.wav",
  "cover": "",
  "previewTime": 12.25,
  "difficulties": [
    {
      "id": "echo_trial_vesper_01",
      "name": "Echo",
      "chart": "res://assets/beatmaps/first_echo_trial.json",
      "rating": 2.0
    }
  ]
}
```

Each chart carries the matching `setId`. The Python linter checks that chart id, path, difficulty name, audio and set id agree with the manifest.

## Rating

`rating` is deliberately a coarse **0–10 authoring estimate**, not a competitive star-rating algorithm. It exists only to sort and communicate prototype difficulty.

Do not build a mathematical difficulty calculator until real playtest telemetry exists. Combat readability, card RNG, movement, enemy geometry and timing windows all affect Réquiem difficulty in ways a note-density formula would miss.

## Authorship rule

When a second difficulty is added, author it around a different intended mastery level rather than cloning the same event stream with fewer events. A lower difficulty may use wider response spacing, simpler enemy overlaps and fewer simultaneous semantic demands. A higher difficulty may change patterns, overlaps and required decisions while preserving the musical phrasing.

## Future selection flow

```text
Mapset catalog
  -> song / Echo Trial
      -> difficulty
          -> modifiers
              -> run
```

This leaves room for campaign-unlocked trials, curated packs and eventually community-authored sets without coupling those systems to the current combat prototype.
